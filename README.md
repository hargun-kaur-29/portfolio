# Hargun Kaur — Portfolio

Static multi-page academic portfolio. No build step, no framework — plain HTML/CSS.

## Pages
- `index.html` — About (identity sidebar + bio, interests, news)
- `cv.html` — Curriculum Vitae (education, skills, certifications)
- `projects.html` — Projects showcase
- `styles.css` — Shared design system
- `script.js` — (unused, safe to delete)
- `assets/favicon.svg` — Site icon
- `assets/Hargun_Kaur_Resume.pdf` — **add your actual resume PDF here**

## Run locally
Open `index.html` in a browser. No server needed.

## Deploy to Vercel
1. Push this folder to a GitHub repo.
2. Go to vercel.com → New Project → import the repo.
3. Framework preset: **Other** (static site). No build command.
4. Deploy.

## To edit content
All text lives directly in each `.html` file. Edit and redeploy.
